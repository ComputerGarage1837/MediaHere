# MediaHere brand assets

Palette: near-black `#07090A`, accent green `#22E67A`, dark green `#14A354`, white text.

- `mediahere-icon.png` — square launcher artwork (the mark on a near-black rounded square).
- `mediahere-icon-transparent.png` — the bare mark with a transparent background.
- `mediahere-logo.png` / `-transparent.png` — stacked logo lock-up (mark over the "MediaHere" wordmark, "Here" in green).

The app's `mipmap-*` launcher icons, `drawable-xhdpi/tv_banner.png`, `drawable-nodpi/logo_wordmark.png` and the Windows
`app.ico` are generated from the mark.

These are presentation assets only; usernames and passwords must never be stored in this repository.
