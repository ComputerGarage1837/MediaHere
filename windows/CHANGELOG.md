# Changelog — MediaHere for Windows

All notable changes to the Windows edition are listed here. The section for each version is shown
to users inside the app when an update is available.

## v1.1.3 — 2026-11-06

### Fixed
- MediaHere now reopens by itself after an update installs.

## v1.1.2 — 2026-11-06

### Changed
- Live TV and Video on Demand cards redrawn to match the design: smooth green swoosh instead of a stray line.

## v1.1.1 — 2026-11-06

### Changed
- New MediaHere logo and app icon.

## v1.1.0 — 2026-11-06

### Changed
- Rebuilt on the latest app: VOD users with their own watched list and My List, casting, expiry reminders and new-episode alerts, cast photos, similar titles, weekly auto backup, and an always-on-top mini player.

## v1.0.0 — 2026-11-05

### Added
- MediaHere for Windows: the same black and green look, new logo and icon as the Android app,
  with the TV guide, Live TV, Video on Demand, downloads, recordings and in-app updates.
